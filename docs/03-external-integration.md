## 2. モック／実データの判断基準

「可能な範囲で実データ連携」という方針（ヒアリング結果）に基づき、以下の優先順位でモック/実データを判断する。

1. **APIキー取得や認定手続きなしで即座に利用できるデータ・認証は実データ連携する**（緑のオープンデータ、公園施設API、LINEログイン、地図タイル、政府統計）
2. **APIは存在するが対象範囲が限定的なもの（区市町村単位の公園施設APIなど）は、対象エリアをそのデータが存在する自治体に絞ってでも実データ連携する**（都全域を無理にモックで埋めない）
3. **認定事業者化・審査・契約が必要なもの（JPKI等）はモックまたは将来拡張の設計余地のみ残す**
4. **公開状況自体が不確実なもの（熱環境データ等）は実装着手時に再調査し、取得できなければ機能から除外する（要件を"データがあれば強化される"任意機能として位置づける）**

- [ ] 「緑のオープンデータ」の実際のダウンロードURL・ライセンス条件・更新頻度
- [ ] 公園施設情報APIのカバー自治体一覧（墨田区以外にどこが対応しているか）とAPIキー取得手順
- [ ] 熱環境・表面温度データが機械可読な形（API/CSV等）で存在するか、東京都環境局への問い合わせが必要か
- [ ] e-Stat等の人口統計APIの利用規約・レート制限
- [ ] LINEログインのデベロッパー登録・審査に要する期間（ハッカソン期日に間に合うか）
