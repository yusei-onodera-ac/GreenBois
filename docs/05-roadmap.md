# 05. ロードマップと完了条件 — GreenVoice TOKYO

前提：原案のロードマップ（Phase1〜3）を、定量的な完了条件（Exit Criteria）まで具体化する。

## Phase 1: ハッカソン（MVP）

**目的**：署名×オープンデータで優先度を可視化する、というコアの価値仮説を動くプロトタイプで示す。

**含む機能**：[01-requirements.md](./01-requirements.md) の In Scope（F1〜F4, F6〜F9）

**完了条件（Exit Criteria）**：

- [ ] 対象エリア（実データが取得できる区）で、地図投稿→署名→優先度スコア表示までが実際に動作するデモができる
- [ ] 少なくとも1つの東京都オープンデータ（緑のオープンデータ or 公園施設API）に実接続している
- [ ] LINEログインによる署名の重複防止が機能している
- [ ] 行政ダッシュボードでスコア順に提案を確認し、ステータスを変更できる
- [ ] 審査員向けに「なぜこのスコアなのか」を説明できる（スコア内訳の可視化）

## Phase 2: モデル区実証

**目的**：特定の区市町村と連携し、実際の公園整備・街頭緑化提案を実際の事業化検討に接続する。

**Phase 1からの追加要件**：

- [ ] 対象自治体の正式な担当部署がダッシュボードを実運用で使用
- [ ] 私有地緑化の受付再開を判断（現在は公有地限定。再開する場合は緑地協定（最低5年）の締結フローを実装し `GREEN_AGREEMENT` エンティティを本格運用する。判断材料は [07-impact-and-policy.md](./07-impact-and-policy.md) 3.4節）
- [ ] 熱環境データ等、追加のオープンデータソースの接続可否を再調査し、取得できれば統合（[03-external-integration.md](./03-external-integration.md) の要検証事項を解消）
- [ ] Park-PFI事業者選定・公園施設長寿命化計画の優先順位づけに、署名データを正式な参考データとして提供する運用を対象自治体と協議（[07-impact-and-policy.md](./07-impact-and-policy.md) 3.2・3.3節）
- [ ] 実際の1件以上の提案が、行政の正式な予算審査プロセスに載る（＝プロダクト外の制度的合意形成が実際に発生する）

**完了条件**：モデル区で実際に1件以上の提案が「採択」ステータスまで到達し、住民・行政双方からのフィードバックを収集済みであること。

## Phase 3: 都内全域展開

**目的**：東京都の正式な参加型予算枠（Participatory Budgeting）制度、および民有地緑化助成金制度との公式連携。

**Phase 2からの追加要件**：

- [ ] マイナンバーカード（JPKI）連携の本格実装、または認定事業者経由の本人確認への切り替え
- [ ] 複数区・都立公園を横断した管轄自動判定（GIS自動判定への全面移行）
- [ ] 東京都の正式な予算制度としての「参加型緑化予算枠」が制度化されていること（プロダクト側だけでは実現できない、行政側の意思決定が前提）

**完了条件**：都の正式な予算プロセスの一部としてGreenVoiceの署名データ・優先度スコアが公式に参照される状態になっていること。

## 各フェーズの前提となる意思決定ポイント

| タイミング | 意思決定事項 | 決定者 |
| --- | --- | --- |
| Phase 1開始前 | 対象エリア（区）の選定 | プロジェクトチーム（実データの取得可否に依存） |
| Phase 1→2 | モデル区との連携可否 | 東京都・区市町村 |
| Phase 2→3 | 「参加型緑化予算」制度の正式化 | 東京都（建設局・環境局等） |
| Phase 3開始前 | JPKI認定事業者化 or 委託の意思決定 | プロジェクトチーム（コスト・体制次第） |

## KPI（原案の想定値の扱い）

原案の「採択率80%」「満足度88%」は目標値であり、Phase 1のMVP規模では統計的に意味のある実測は困難。Phase 1では代わりに以下を計測する：

- 投稿数、署名達成率（閾値到達した提案の割合）
- 行政ダッシュボードでの審査対応時間（受付→ステータス変更までの日数）
- デモ・実証参加者からの定性フィードバック

Phase 2以降、対象自治体の実際の採択率・満足度調査と接続し、原案の目標値との比較を開始する。検証すべき仮説とエビデンスの対応は [07-impact-and-policy.md](./07-impact-and-policy.md) 4章の一覧を参照。
