# 00. 構想サマリー — GreenVoice TOKYO

> 東京都オープンデータ・ハッカソン提案事業「GreenVoice TOKYO」の構想を、実装可能なレベルまで再整理したドキュメント群の起点。原案（PDF「新規行政サービス事業案『GreenVoice TOKYO』」）の内容を土台に、後続の `01-requirements.md` 以降で詳細化する。

## 1. 一言で言うと

都民が「街に必要な緑」をマップ上に提案し、デジタル署名で共感を可視化し、オープンデータによるAIスコアリングと組み合わせて、都・区市町村の「参加型緑化予算」から実際に予算を引き出す、ボトムアップ型グリーンインフラ・プラットフォーム。**都民のみが利用できるサービス**であり、企業アカウントは設けない（私有地・企業敷地への行政補助金交付は法的に不可能なため。7章参照）。

## 2. 扱う範囲（スコープ基準）

GreenVoiceは「木を植えてくれるサービス」でも「ベンチを置いてくれるサービス」でもなく、**まちの「みどり」に関わる行政への声・要望・助成申請を幅広く受け付けるプラットフォーム**である。「緑を増やす」提案だけでなく、「緑を適切に管理する」（危険木の伐採・剪定など）ための支援要望も対象に含む。カテゴリ（ジャンル）はこの考え方に沿って4種類＋その他に整理している（[01-requirements.md](./01-requirements.md) 参照）。

| ジャンル | 具体例 | 「緑を増やす／管理する」のどちら側か |
| --- | --- | --- |
| 公園設備 | ベンチ・日よけ・遊具など、公園利用に関わる設備要望 | 緑を使いやすくする（周辺整備） |
| 植樹・緑化（公有地） | 街路樹・公園緑化・ヒートアイランド対策の植栽要望 | 緑を増やす |
| 私有地緑化 | 個人の敷地・屋上緑化 | 緑を増やす |
| 樹木管理・伐採支援 | 私有地の危険木の伐採・剪定、老木の維持管理に対する助成申請 | 緑を適切に管理する（減らす／整える） |
| その他 | 上記に当てはまらない、まちの「みどり」に関する提案・相談 | — |

**対象外の例（基準の明確化のため）**：緑化・みどりと関係のない一般的な公共施設要望（道路の陥没、ゴミ収集等）、個人間の金銭トラブル、緑化と無関係な福祉・教育サービスへの要望。これらは対象外である旨を投稿画面・ヘルプで明示する。

> **実装上の現在の方針**：私有地緑化は上表のとおり構想上の中核類型の一つだが、①管轄自動判定・審査フローをまず公共領域で確立すること、②**私有地・企業敷地への行政補助金交付は法律上できない**こと、の2つの理由により、現在の新規投稿は**都・区市町村が管理する公有地（公園・図書館・道路等）に限定**している。私有地に関する相談を今後どう扱うか（補助金を伴わない形での関わり方）は [07-impact-and-policy.md](./07-impact-and-policy.md) 3.4節を参照。

## 3. 課題構造（原案より）

| 視点 | 課題 |
| --- | --- |
| 都民 | 公園設備等への要望はあるが、手続きが複雑で個人の声が予算獲得まで届かない |
| 東京都・行政 | 予算配分の優先順位を判断する定量的エビデンスや住民合意形成プロセスが不足 |

**構造的な本質**：「声（ニーズの所在）」と「予算（意思決定の根拠）」が分断されている。GreenVoiceはこの2つを「署名数 × オープンデータ」で橋渡しする。

## 4. 三方よし（ステークホルダー別価値）

| ステークホルダー | Before | After（GreenVoice導入後） |
| --- | --- | --- |
| 都民・地域住民 | 声を伝える場がなく諦め | 署名が公園整備・緑化に直結 |
| 東京都・区市町村 | 予算配分の根拠獲得が困難 | 住民需要データ×GISデータで投資判断の精度が向上 |
| 民間企業（間接的） | Park-PFI等の公募時に、どの公園にニーズがあるか客観的な根拠がない | GreenVoiceの署名データを公募提案の裏付けとして活用できる（[07-impact-and-policy.md](./07-impact-and-policy.md) 3.2節） |

> 民間企業はGreenVoiceに直接ログイン・投稿はしない（都民専用サービスのため）。企業が関わるのは、公有地の運営に民間活力を導入するPark-PFI制度等を通じた間接的な形のみ。私有地・企業敷地への行政補助金交付は法律上できないため、原案にあった「企業のCSR/ESG緑化への補助金」という関わり方は採用しない。

## 5. 行政経営の再設計レベル（原案の「レベル1〜4」）

| レベル | アプローチ | GreenVoiceでの具体像 |
| --- | --- | --- |
| 1. インタラクション | 接点の改善 | 1分で完了する投稿・ワンタップ署名UI |
| 2. サービスデザイン | サービス全体の再設計 | 都民・都庁・区市町村が同一基盤で進捗共有 |
| 3. システムデザイン | 制度・組織を変える | 署名数連動の「参加型緑化予算」枠の新設 |
| 4. デザインフューチャーズ | 将来の行政を設計する | オープンデータ×ボトムアップ参加による継続的実装 |

このドキュメント群が主に扱うのは **レベル1〜2（プロダクトとして作れる部分）**。レベル3（予算枠という制度そのものの新設）は東京都・区市町村の意思決定を要するため、GreenVoice側は「レベル3が発足した際にそのまま使える運用基盤」として設計する（詳細は `01-requirements.md` のスコープ定義を参照）。

## 6. 期待効果（原案の想定値・要検証）

- 従来の要望採択率 25% → GreenVoice導入後（想定）80%
- 都民の緑化施策満足度（想定）88%

> **要検証**：これらの数値は原案（ピッチ資料）における目標値であり、実測値・裏付けとなる調査は存在しない。要件定義・KPI設計時は「目標値」として扱い、MVP実証で計測可能な代替指標（例：投稿数、署名達成率、審査委員会への提出件数）を `05-roadmap.md` で別途定義する。外部の学術研究・政府統計に基づく期待効果の裏付けは [07-impact-and-policy.md](./07-impact-and-policy.md) を参照。

## 7. 何が仮説で、何が確認済みか

| 項目 | ステータス |
| --- | --- |
| 都民の緑化ニーズの分断・行政の縦割り課題 | 一般的な行政課題として妥当性は高い（仮説だが説得力あり） |
| 東京都の緑地関連オープンデータの存在 | **確認済み**（`03-external-integration.md` 参照） |
| 「参加型緑化予算」という制度の実在 | **未確立**（都に前例なし。世田谷区Decidimは意見募集止まりで予算直結ではない） |
| マイナンバーカード署名連携 | 技術的に可能だが民間導入のハードルが高い（**要検証**） |
| AIスコアリング用の熱環境（表面温度）データ | 公開状況が不明瞭（**要検証**） |

後続ドキュメントでは、この「仮説／確認済み／要検証」の区分を踏まえてスコープを線引きする。
