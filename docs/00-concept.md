# 00. 構想サマリー — GreenVoice TOKYO

## 1. 一言で言うと

都民が「街に必要な緑」を地図上に提案し、デジタル署名で共感を可視化し、行政側はその声を優先度スコア付きのダッシュボードで確認して対応する、ボトムアップ型グリーンインフラ・プラットフォーム。**都民のみが利用できるサービス**であり、企業アカウントは設けない(私有地・企業敷地への行政補助金交付は法的に不可能なため)。

## 2. 扱う範囲(スコープ基準)

「木を植えてくれるサービス」でも「ベンチを置いてくれるサービス」でもなく、**まちの「みどり」に関わる行政への声・要望を幅広く受け付けるプラットフォーム**。「緑を増やす」提案だけでなく、「緑を適切に管理する」(危険木の伐採・剪定など)ための支援要望も対象に含む。

| ジャンル | 具体例 |
| --- | --- |
| 公園設備 | ベンチ・日よけ・遊具など、公園利用に関わる設備要望 |
| 植樹・緑化 | 街路樹・公園緑化・ヒートアイランド対策の植栽要望(公有地) |
| 私有地緑化 | 個人の敷地・屋上緑化(既存データのみ。新規投稿は不可) |
| 樹木管理 | 私有地の危険木の伐採・剪定、老木の維持管理に対する助成申請 |
| その他 | 上記に当てはまらない、まちの「みどり」に関する提案・相談 |

**新規投稿は都・区市町村が管理する公有地(公園・図書館・道路等)に限定**している。理由は2つ:
1. 管轄自動判定・審査フローをまず公共領域で確立するため。
2. 私有地・企業敷地への行政補助金交付は法律上できないため。

私有地緑化のカテゴリ自体は過去データとして行政ダッシュボードに残るが、都民向けの新規投稿フォーム・絞り込み・地図凡例からは外している。

## 3. 課題構造

| 視点 | 課題 |
| --- | --- |
| 都民 | 公園設備等への要望はあるが、手続きが複雑で個人の声が予算獲得まで届かない |
| 東京都・行政 | 予算配分の優先順位を判断する定量的エビデンスや、どこの部署が担当かの判断に手間がかかる |

**構造的な本質**:「声(ニーズの所在)」「予算判断の根拠」「担当部署の特定」が分断されている。GreenVoiceはこれらを「署名数 × オープンデータによる管轄自動判定」で橋渡しする。

## 4. 現在の到達点(実装済み)

原案(ピッチ資料)段階だった構想のうち、以下は**実際に動くアプリとして実装済み**:

- 都民が地図上で場所を指定して提案を投稿し(写真最大5枚)、他の都民が署名できる。
- 提案の場所から、管轄する行政部署を**東京都オープンデータの実データ**(区ごとの公園一覧、約3,300件を取り込み済み)を使って自動判定する(F9)。
- 行政ダッシュボードで、署名数とオープンデータスコアを合成した優先度順に提案を確認し、ステータスを変更できる。
- 都民向け画面には氏名等の個人情報を一切表示せず、行政向け画面のみ本名を表示する(ハンドル名との分離設計)。

未実装・今後の課題は [05-roadmap.md](./05-roadmap.md) を参照。
